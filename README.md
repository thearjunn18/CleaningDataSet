# 🧹 Employee Dataset Cleaning

A beginner-friendly **data cleaning project using Python, Pandas, and NumPy**. The dataset contains intentionally messy employee data with missing, infinite, negative, and unrealistic values.

## 🛠️ Technologies

* Python
* Pandas
* NumPy
* CSV

## 🔍 Cleaning Performed

* Handled missing values
* Replaced `inf` and `-inf`
* Identified invalid/negative values
* Used mean/median to fill missing numerical data
* Exported the cleaned dataset as a new CSV file

## 📂 Files

```text
├── data_cleaning.py
├── dirty_employee_dataset_30.csv
├── Cleaned_DataSet.csv
└── README.md
```

## 🚀 Run

```bash
pip install pandas numpy
python data_cleaning.py
```
